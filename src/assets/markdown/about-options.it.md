Questa pagina riunisce le opzioni e i log di utilizzo del catalogo.

I log, come i preferiti e le altre informazioni dell'utente, sono salvati nel browser web e restano completamente privati (tecnicamente, solo l'utente stesso può accedervi).

Le informazioni dell'utente possono essere esportate in un file zip per essere conservate e/o importate in un altro browser.
