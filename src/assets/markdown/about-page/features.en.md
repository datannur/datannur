datannur is a portable data catalog: it runs in the browser, does not require a server, and brings together the information needed to find, understand, and use data.

This page gives a quick overview of the main features. For a more illustrated presentation, see the [complete version on the website](https://datannur.com/fonctionnalites/). For installation, configuration, and integrations, see the [technical documentation](https://docs.datannur.com/app/).

## Explore the catalog

Navigation combines several entry points: organizations, folders, tags, datasets, variables, documents, and business concepts. Each item has its own page, with tabs adapted to its role in the catalog.

Global search helps you quickly find an item from its name, description, or metadata. Tables complement search with sorting, column filters, and exports.

## Understand metadata

The About pages gather essential information: identifier, description, owner, folder, license, dates, tags, and related links. Markdown or PDF documents can be linked directly to catalog items to keep business documentation close to the data.

datannur can also represent a business glossary and relationships between variables. These links help clarify the meaning of data, identify dependencies, and better understand transformation chains.

## Analyze and track changes

Statistics tabs provide a summary view of available content: value distributions, frequencies, missing information, folder dimensions, or variable characteristics. When a table preview is available, it lets you browse the first rows of a dataset directly.

The history highlights changes made to catalog items: additions, deletions, value updates, or date changes. This makes it easier to track metadata quality and stability over time.

## Work locally

Favorites, recent searches, preferences, and usage logs remain stored in the browser. The catalog can therefore be used without an internet connection while keeping user-specific settings.

This local data can be reset, exported, or imported from the Options page. The catalog can also expose its metadata through a REST API or produce a DCAT export when these features are enabled.
