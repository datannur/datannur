datannur est un catalogue de données portable : il fonctionne dans le navigateur, sans serveur obligatoire, et rassemble dans une même interface les informations utiles pour retrouver, comprendre et exploiter les données.

Cette page donne un aperçu rapide des principales fonctions. Pour une présentation plus illustrée, consultez la [version complète sur le site web](https://datannur.com/fonctionnalites/). Pour l'installation, la configuration et les intégrations, consultez la [documentation technique](https://docs.datannur.com/app/).

## Explorer le catalogue

La navigation combine plusieurs portes d'entrée : organisations, dossiers, mots clés, jeux de données, variables, documents et concepts métier. Chaque élément dispose de sa propre page, avec des onglets adaptés à son rôle dans le catalogue.

La recherche globale permet de retrouver rapidement un élément à partir de son nom, de sa description ou de ses métadonnées. Les tableaux complètent cette recherche avec le tri, les filtres par colonne et les exports.

## Comprendre les métadonnées

Les pages « À propos » rassemblent les informations essentielles : identifiant, description, responsable, dossier, licence, dates, mots clés et liens associés. Les documents Markdown ou PDF peuvent être reliés directement aux éléments du catalogue pour garder la documentation métier au même endroit que les données.

datannur peut aussi représenter un glossaire métier et des relations entre variables. Ces liens aident à clarifier le sens des données, à repérer les dépendances et à mieux comprendre les chaînes de transformation.

## Analyser et suivre l'évolution

Les onglets statistiques donnent une vue synthétique du contenu disponible : répartition des valeurs, fréquences, informations manquantes, dimensions des dossiers ou caractéristiques des variables. Quand un aperçu tabulaire est disponible, il permet de parcourir directement les premières lignes d'un jeu de données.

L'historique met en évidence les changements apportés aux éléments du catalogue : ajouts, suppressions, modifications de valeurs ou évolution des dates. Il devient ainsi plus simple de suivre la qualité et la stabilité des métadonnées dans le temps.

## Travailler localement

Les favoris, recherches récentes, préférences et journaux d'utilisation restent stockés dans le navigateur. Le catalogue peut donc être utilisé sans connexion internet, tout en conservant les réglages propres à l'utilisateur.

Ces données locales peuvent être réinitialisées, exportées ou importées depuis la page Options. Le catalogue peut aussi exposer ses métadonnées via une API REST ou produire un export DCAT lorsque ces fonctions sont activées.
