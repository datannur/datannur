# Explore the data catalog

This catalog lets you explore datasets, variables, enumerations, documentation, and the main relationships between items.

Use search, the tree view, or the AI assistant to start exploring.
The [Structure](about?tab=aboutStructure) and [Features](about?tab=aboutFeatures) pages also help explain how the catalog is organized and the main ways to use the interface.
